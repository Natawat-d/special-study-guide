# Special Study guide

Plain-language companions to the AIT Special Study report *Short-Term
Soil-Moisture Forecasting in Pathum Thani: A Quality-Filtered SMAP L3
Benchmark*. Results are for the selected SMAP L3 cell, not the whole province.

- `index.html`: front page
- `guide.html`: the study explained, in seven chapters
- `literature.html`: which papers to highlight

These pages are generated by `code/explainer_page/publish.py` in the private
project repository. Edit the generator there, not these files.
